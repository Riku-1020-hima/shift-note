# シフトノート

飲食店向けのシフト作成アプリです。スタッフはスマホで希望を出し、店長はボタン1つでシフトの下書きを自動で作れます。

## 主な機能

- **希望の提出(スタッフ)**:一人ひとり専用のURLから、ログインなしで「入れる日と時間帯」をタップして送れます。「土日だけ」などの一括選択、店長へのひとことにも対応しています
- **シフトの自動作成**:希望・必要な人数(平日/土日)・「週◯日まで」の上限を見て、人が集まりにくい枠から順に、偏りが出ないように組みます。空いている枠だけ埋める/全部作り直すを選べます
- **手で直す**:日付ごとに、希望を出した人を上に並べて入れ替えられます。人が足りない枠は赤く表示されます
- **公開**:確定するとスタッフのページに「これからのシフト」が表示されます
- **印刷・掲示用の表**:スタッフ × 日付の一覧をA4横で印刷できます
- 定休日の設定、提出状況の確認、締め切り日、LINEで送れる案内文のコピー、各画面の使い方ガイド、スマホ対応

## 使っている技術

- Laravel 13 / PHP 8.4
- Blade + Tailwind CSS 4(Vite)
- SQLite(開発)/ MySQL(本番:Laravel Cloud)

## 動かし方(Laravel Herd)

```bash
bash ~/Herd/shift-note-setup/setup.sh
```

http://shift-note.test を開き、デモアカウントでログインできます。

- メールアドレス:`demo@example.com`
- パスワード:`password`

デモデータには、架空の飲食店(スタッフ10人、ランチ・ディナー、水曜定休)が入っています。今月のシフトは公開済み、来月は8人が希望を提出済みで、「自動で作る」を試せる状態です。

## 自動作成のしくみ(app/Services/ShiftPlanner.php)

1. 埋める必要がある枠を洗い出し、「候補の人数 − 必要な人数」が小さい(人が集まりにくい)枠から先に埋める
2. 候補の中では、その月にまだ入っている回数が少ない人を優先する
3. 週の上限(月をまたぐ週も前後の月を含めて数える)と、同じ日に時間が重なる枠を避ける
4. 希望を出していない日には入れず、足りない枠は一覧で知らせる

## 公開デモ版の設定

環境変数で `DEMO_MODE=true` にすると、ログイン画面にデモ用アカウントが表示され、新規登録とログイン情報の変更ができなくなります。毎日4時(日本時間)に `php artisan demo:reset` でデータが初期状態に戻ります。
